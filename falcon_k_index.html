Falcon K V3 가변 프레임 구조

기존 256B Header는 유지하고, Falcon K일 때만 Header 뒤에 72000개 고정 IndexTable을 붙이는 방식
핵심: Falcon K는 W/H로 frame 크기를 읽지 않는다.
Falcon K 원본은 고정 이미지가 아니라 idx별 packet/block stream이다. 그래서 frame마다 point 수가 달라질 수 있고, frame의 시작 위치와 크기는 IndexTable로 찾는다.

기존 고정 frame 모델은 W * H로 frame payload 크기를 계산할 수 있다. 하지만 Falcon K IndexTable 방식에서는 index[n].size가 해당 frame의 실제 크기다. W/H는 reader가 frame seek와 크기 계산에 쓰지 않는다.

struct LbcFrameIndexEntry
{
  uint64_t offset;
  uint32_t size;
  uint32_t reserved;
};

sizeof(LbcFrameIndexEntry) == 16
