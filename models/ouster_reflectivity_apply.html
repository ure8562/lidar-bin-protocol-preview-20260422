Ouster Reflectivity 적용 방식

Ouster packet의 RFL8 값을 V3 바이너리의 Reflectivity shape로 저장하고, 뷰어에서는 이 값을 3D point cloud 색상에 우선 적용한다.

RFL8
uint8
shape flag bit4
API v6

Reflectivity가 뭔가?

Reflectivity는 물체 표면이 라이다 빛을 얼마나 잘 반사했는지 나타내는 값이다. 단순히 가까우면 밝고 멀면 어두운 값이라기보다, 표면 재질과 반사 특성이 어느 정도 보정된 채널이다.

그래서 3D point cloud에 Reflectivity를 색으로 입히면, 같은 공간이라도 금속, 벽, 바닥, 케이블 같은 표면 차이가 더 잘 드러난다.
Range
RNG19. 거리. 좌표 계산과 Depth에 사용.
Reflectivity
RFL8. 보정 반사율. 이번에 별도 shape로 저장.
Signal
SIG16. 수신 신호 세기. 2D Signal 이미지에 사용.
NearIR
NIR16. 주변 적외선 성분. 기존 Ambient로 저장.

현재 Ouster 구현은 RNG19_RFL8_SIG16_NIR16 프로파일을 대상으로 한다. 채널 하나의 measurement block에서 Reflectivity는 range word 바로 다음 1바이트다.

V3 shape에 어떻게 추가했나

기존 V3 출력은 PCD, Depth, Ambient, Intensity 네 가지가 기본이었다. 이번에 Reflectivity를 bit4로 추가해서, 요청 시 다섯 번째 shape로 저장한다.

기본값은 호환성을 위해 0x000F로 유지했다. Reflectivity까지 포함하려면 shapeFlags = 0x001F로 요청한다.

저장 흐름

1
PCAP 파싱
Ouster UDP packet에서 column과 channel을 순서대로 읽는다.
2
RFL8 추출
각 channel block의 src[4]를 reflectivity 배열에 저장한다.
3
Frame 누적
pointIndex = column * pixels + channel 위치에 값을 넣는다.
4
Header 작성
shape descriptor에 Reflectivity를 uint8 shape로 기록한다.
5
Payload 저장
Reflectivity는 1바이트라 엔디안 변환 없이 그대로 쓴다.
// Ouster channel block에서 RFL8 추출
column.reflectivity[channel] = src[4];

// frame payload 위치에 누적
pointIndex = columnIndex * pixelsPerColumn + channel;
frame.reflectivity[pointIndex] = column.reflectivity[channel];

// Reflectivity shape 요청 시 payload에 저장
if ((shapeFlags & LBC_SHAPE_FLAG_REFLECTIVITY) != 0)
{
  WriteU8Array(ofs, frame.reflectivity.data(), frame.reflectivity.size());
}

뷰어에서 어떻게 썼나

뷰어는 V3 frame을 읽을 때 Reflectivity shape가 있으면 그 값을 우선 point intensity로 사용한다. 없으면 기존 Signal 값을 fallback으로 쓴다.

pointColorValues = reflectivityValues ?? signalValues ?? zeros

point.Intensity = pointColorValues[index]

WPF의 PointsVisual3D는 point마다 완전히 다른 색을 직접 주기 어렵기 때문에, 값을 8개 bucket으로 나눈 뒤 bucket마다 다른 색의 point collection으로 그린다.

lowClip = percentile(validReflectivity, 2%)
highClip = percentile(validReflectivity, 98%)

normalized = clamp((value - lowClip) / (highClip - lowClip), 0, 1)
boosted = sqrt(normalized)
bucket = floor(boosted * 8)

2%~98% clipping은 일부 아주 어둡거나 밝은 점 때문에 전체 색 대비가 죽는 것을 막기 위한 처리다. sqrt는 중간 이하 값도 조금 더 잘 보이도록 밝기 분포를 끌어올리는 역할을 한다.

Signal과 Reflectivity의 역할 분리

둘 다 intensity처럼 보일 수 있지만, 이번 적용에서는 역할을 분리했다.

Reflectivity
3D point cloud 색상에 우선 사용. 표면 반사 특성을 보는 목적.
Signal
하단 2D Signal 이미지에 사용. 센서가 받은 신호 세기 패턴을 보는 목적.
Fallback
Reflectivity shape가 없는 기존 V3 파일은 Signal로 3D 색상을 대신 입힌다.
Depth
선택/거리/깊이 이미지용이며, Reflectivity와 다른 값이다.

주의할 점

  • Reflectivity는 Ouster의 RFL8 값이라 0..255 범위의 uint8로 저장한다.
  • 기존 호환성을 위해 기본 shapeFlags는 0x000F이고, Reflectivity 포함 파일은 0x001F로 만든다.
  • Reflectivity는 이미 보정된 반사율 계열 값이므로 Signal과 완전히 같은 의미가 아니다.
  • 현재 3D 색상은 8단계 bucket 표현이다. 더 부드러운 컬러맵이 필요하면 point renderer 구조를 바꿔야 한다.
  • Studio와 같은 색감을 내려면 컬러맵, clipping, gamma, auto-level 정책을 더 맞춰야 한다.
