SPSS 컨테이너 지도화 알고리즘 아이디어

Ouster PCD를 이용해 현장 안의 컨테이너 박스 위치와 적재 구조를 지도처럼 표현하는 1차 접근안이다. 지금 단계는 구현 확정안이 아니라, 실험 방향을 잡기 위한 설계 메모다.

문제 정의

SPSS에서 보고 싶은 것은 단순한 점 구름이 아니라, 점 구름 안에 있는 컨테이너 박스 구조다. 컨테이너가 어디에 있고, 어느 방향으로 놓였고, 몇 줄/몇 층으로 쌓였는지 알 수 있으면 지도로 바꿀 수 있다.

입력
frame별 PCD, Depth, Reflectivity, Signal
중간 표현
BEV height map, density map, reflectivity map
출력
컨테이너 후보 사각형, 위치, 방향, 크기, 층/열 구조
목표
한 프레임에서 컨테이너 후보를 잡고, 이후 시간 누적으로 안정화
첫 버전은 딥러닝보다 기하 기반이 좋아 보인다. 컨테이너는 대체로 크고 평평한 직사각형 구조라서 height map + rectangle fitting만으로도 의미 있는 결과를 낼 가능성이 있다.

데이터 역할 분리

각 채널을 같은 의미로 섞기보다, 역할을 분명히 나누면 알고리즘이 단순해진다.

XYZ / PCD
박스의 형태, 위치, 방향, 높이를 판단하는 주 데이터
Depth
센서 기준 거리, outlier 제거와 깊이 기반 필터링에 사용
Reflectivity
표면 경계 강화, 재질 차이, 낮은 밀도 영역 보조 판단
Signal
2D 품질 확인, raw 수신 강도 진단, 센서 상태 확인
Reflectivity는 컨테이너를 직접 검출하는 주 데이터라기보다, 박스 경계와 표면 차이를 보조하는 정보로 쓰는 편이 안전하다.

핵심 아이디어: PCD를 BEV 지도로 변환

3D point를 위에서 내려다본 2D grid로 누적한다. 각 cell은 하나의 작은 바닥 면적을 뜻하고, cell마다 높이, 점 개수, 반사율 평균 같은 값을 저장한다.

cellX = floor((x - minX) / gridSize)
cellY = floor((y - minY) / gridSize)

heightMap[cell] = max(z)
densityMap[cell] = pointCount
reflectMap[cell] = average(reflectivity)
3D PCD 관찰점 구름
X / Y / Z
BEV Map위에서 본 지도
gridSize = 0.1m or 0.2m

1차 처리 파이프라인

1
좌표 정렬
센서 기울기와 바닥 기준을 맞춘다. 고정 설치면 한 번 캘리브레이션한 변환을 재사용한다.
2
노이즈 제거
너무 먼 점, 고립점, 비정상 depth, 바닥 아래 점을 제거한다.
3
BEV Grid
X-Y 평면에 cell을 만들고 height, density, reflectivity를 누적한다.
4
후보 영역
높이와 밀도가 일정한 cell을 묶어 connected component로 만든다.
5
사각형 추정
각 component에 oriented bounding box를 맞춰 컨테이너 후보를 만든다.
6
구조화
방향, 간격, 높이를 기준으로 열, 행, 층 구조를 추정한다.

컨테이너 후보 조건

컨테이너는 BEV에서 일정 크기의 직사각형 덩어리로 보인다고 가정한다. 완전히 꽉 찬 면이 아니더라도, 외곽과 높이 분포가 안정적이면 후보로 볼 수 있다.

candidate if:
areaMin < componentArea < areaMax
heightRange is stable
densityMean > threshold
rectangleFitScore > threshold
  • 너무 작은 영역은 노이즈나 사람/장비일 가능성이 높다.
  • 너무 큰 영역은 여러 컨테이너가 붙어 있는 그룹일 수 있다.
  • 직사각형 점수는 OBB 면적 대비 실제 occupied cell 비율로 볼 수 있다.

박스 정보 출력

검출된 컨테이너 후보는 단순 점 집합이 아니라, 지도에서 사용할 수 있는 구조화된 객체로 저장한다.

ContainerBox {
  centerX, centerY, centerZ,
  width, length, height,
  yawAngle,
  confidence,
  rowIndex, columnIndex, layerIndex
}
이 객체가 생기면 화면에는 사각형 overlay를 그릴 수 있고, 나중에는 빈 슬롯, 기울어짐, 돌출 같은 상태 판단도 붙일 수 있다.

상태 판단 아이디어

빈 공간

예상 슬롯 위치에 height/density가 없으면 empty slot 후보로 표시한다.

돌출

정렬된 grid에서 특정 박스가 기준선 밖으로 튀어나오면 offset으로 판단한다.

기울어짐

같은 행의 평균 yaw와 차이가 크면 회전 이상 후보로 본다.

층 높이

z 높이 분포를 클러스터링해 1층, 2층, 3층 구조를 나눈다.

시간 누적 지도

한 프레임만으로는 빈 부분, 가림, 먼 거리 노이즈가 있을 수 있다. 센서나 차량이 움직이거나 여러 frame을 볼 수 있다면, 같은 좌표계에 누적해서 안정적인 지도를 만든다.

mapCell.score = decay * oldScore + currentObservation
mapCell.height = robustMaxOrMedian(previousHeights)
box.confidence = temporalConsistency(box over N frames)
처음부터 완전한 SLAM을 목표로 하기보다, 고정 센서 기준이면 고정 좌표계 누적부터 시작하는 편이 현실적이다. 움직이는 플랫폼이면 odometry나 외부 pose가 필요하다.

개발 단계 제안

Phase 1. 한 프레임

현재 frame에서 BEV height map을 만들고, 컨테이너 후보 사각형을 화면에 표시한다.

Phase 2. 안정화

여러 frame에서 후보를 누적하고, 노이즈/가림에 강하게 만든다.

Phase 3. 상태 판단

빈 슬롯, 돌출, 기울어짐, 층/열 구조를 자동으로 라벨링한다.

초기 실험 체크리스트

  • PCD 좌표계에서 바닥 방향과 컨테이너 장축 방향이 안정적인지 확인한다.
  • grid size를 0.1m, 0.2m, 0.3m로 바꿔가며 컨테이너 외곽이 얼마나 선명한지 본다.
  • height threshold만으로 컨테이너 영역이 분리되는지 확인한다.
  • Reflectivity를 섞었을 때 경계가 더 좋아지는지 비교한다.
  • 한 프레임 OBB 결과와 여러 프레임 누적 OBB 결과를 비교한다.
  • 검출 결과를 PointCloud 화면 위에 사각형 overlay로 표시해 사람이 바로 검수할 수 있게 한다.
